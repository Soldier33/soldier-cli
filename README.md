
# soldier-cli

![Npm Version](https://img.shields.io/badge/soldier-cli_v1.0.3-green)

## 📖简介

- 用于快速搭建前端项目的命令行`cli`工具

## 📕 模板

-   ✅ 快速生成  模板

## 📦 安装

```bash
  npm i soldier-cli -g
```

## 🚩使用

```bash
# 使用模板创建一个新项目
soldier create

# 执行项目文件夹名称并选择模板创建新项目
soldier create [prjName]

# 更新脚手架到最新版本
soldier update

# 查看脚手架版本
soldier -v

soldier --version
```


# 其他问题

### 修改全局
- git config  --global user.name 你要设置的用户名；
- git config  --global user.email 你要设置的邮箱;

### 修改当前项目
- git config user.name 你要设置的用户名;
- git config user.email 你要设置的邮箱;
